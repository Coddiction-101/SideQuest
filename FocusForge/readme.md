# FocusForge

A minimal deep-work timer designed to help you choose one task, reduce distractions, and stay focused until the session ends.

## Live project

[View FocusForge](https://coddiction-101.github.io/SideQuest/FocusForge/)

## Features

- Circular duration selector with custom time support
- Custom timer durations
- Named tasks for each focus session
- Start and pause controls
- Live countdown timer
- Space to start or pause and R to reset (shortcuts are disabled in form fields)
- Timer state and completed sessions saved locally, including active sessions across refreshes
- Optional focus-to-break cycles with a configurable break duration
- Recent session history and daily/weekly focus summaries
- Optional completion sound and browser notifications
- Minimal responsive interface
